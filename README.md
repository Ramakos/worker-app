# Ramakos Worker App

> **Staff Order & Shift Management Mobile Platform** for **Ramakos Catering Service** (Kumasi Branch).  
> *"good food, good taste"* — Phone: `+233 32 249 6812`

---

## 1. Overview

**Ramakos Worker App** is the mobile-first floor application designed for waiters, servers, and roaming floor staff at Ramakos. It enables quick staff PIN login, taking table-side and pocket orders, monitoring order preparation statuses, and managing shift activity.

---

## 2. Key Features

- **Staff PIN Authentication**: Fast 4-digit PIN access linked to active staff profiles in Supabase.
- **Pocket Orders**: Quick order capture with item add-ons, portion notes, and direct dispatch to the Kitchen Display System.
- **Shift & Pocket Tracker**: Real-time shift tracking and active order count monitoring.
- **PWA Ready**: Mobile-first responsive layout installable on staff mobile devices.

---

## 3. Technology Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Backend**: [Supabase](https://supabase.com/) PostgreSQL + Realtime
- **Icons**: [Lucide React](https://lucide.dev/)
